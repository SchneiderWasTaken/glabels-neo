# Security policy

## Reporting a vulnerability
Please report vulnerabilities **privately** using GitHub's
[private vulnerability reporting](https://github.com/SchneiderWasTaken/glabels-neo/security/advisories/new)
(Security tab > Report a vulnerability). Please do not open a public issue.

gLabels Neo is a small volunteer project, so responses are best effort. We aim to
acknowledge reports within a few days and to publish a fix or mitigation as soon as is
practical.

## Supported versions
The latest stable release and the `main` branch.

## Scope
- In scope: code in this repository, its build and packaging scripts, and the release artifacts we publish.
- Out of scope: issues in the original [gLabels](https://github.com/j-evins/glabels-qt)
  that are not specific to this fork (report those upstream) and bugs in third-party
  libraries (report those to the library maintainers).
