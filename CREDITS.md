Fork Features
-------------

The following features were added in gLabels-neo:

- **Fill page** — interactive batch-fill table with live preview
- **Deploy tab** — standalone kiosk builder
- **Kiosk mode** (`glabels-fill`) — stripped-down fill-and-print app
- **Single-file SFX** — self-extracting static-Qt kiosk
- **CSV/Excel import/export** — via QXlsx and built-in CSV parser
- **Per-column locking** — data-source pre-fill model
