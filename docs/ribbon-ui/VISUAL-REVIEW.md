# Visual review of the merged tree against the mockups

Done by Opus on 2026-11-25 on `feat/ribbon-ui-theme` (merged tree, b246777 plus the commits
listed in the final report). Captures are in [`screenshots/`](screenshots/), produced by
`TestThemeGallery` (`mainWindowScreens` and `dialogs`) with `GLABELS_THEME_SCREENSHOTS` set,
on the offscreen platform with a 1920 x 1080 virtual screen and the Windows fonts
(`QT_QPA_FONTDIR=C:\Windows\Fonts`). Main window captures are 1440 x 900 of the client area,
so they have **no native title bar**: everything sits about 32 px higher than in the mockups.

The project used is generated by the test: Avery 5095 with a text, an image, a box, an
ellipse, a line and a Code 39 barcode. There is no merge source and no variables, so Fields,
Variables, merge records and the Merge control card are empty or hidden **by design** (the
mockups show sample data). Units follow the settings default (inches here, mm in mockups).

Fonts: Inter and JetBrains Mono are not installed, so everything renders in Segoe UI and
Consolas. Inter has a larger x-height, so text in the captures looks about 1 px smaller than in
the mockups at the same pixel size. Not a defect.
