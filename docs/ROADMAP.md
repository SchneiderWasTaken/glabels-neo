# gLabels Neo roadmap

gLabels Neo is a modernized fork of [gLabels](https://github.com/j-evins/glabels-qt).
Goal: a really good, easy-to-get label making tool that stays close to upstream.

| MVP | Theme | Status | Plan |
|---|---|---|---|
| 0 | Foundation: rebase on upstream, license/attribution, brand, governance | in progress | [mvp-0-foundation](plans/mvp-0-foundation.md) |
| 1 | Robust CI/CD, packaging, automatic releases ("download and go") | planned | [mvp-1-cicd](plans/mvp-1-cicd.md) |
| 2 | Website on GitHub Pages, built for search (per-template pages) | built, not yet published | [mvp-2-website](plans/mvp-2-website.md) |
| 3 | Issue triage and automated fix attempts (GitHub Actions + VPS), human escalation | planned | - |
| 4 | Differentiating features, ranked by upstream demand (printer rotation #46, tape auto-length #115, thermal/ZPL, quantity per record) | planned | - |

Upstream issue priorities that inform MVP 4 are documented in the project notes;
fixes that are generally useful are offered back to gLabels upstream.
