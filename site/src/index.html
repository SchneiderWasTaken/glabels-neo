Questions

Is gLabels Neo really free?

Yes. It is open-source software under the GPL-3.0-or-later license. There is no account, no trial, no watermark, no ads and no per-label fee.

Does it work with Avery label sheets?

Yes. It includes templates for Avery sheets such as 5160, 5163 and 8160, plus Online Labels, Herma, Hisago, Rayfilm and many other makers, nearly 1,500 in total. If your sheet is not listed, the Product Template Designer lets you create it.

Which computers does it run on?

Windows 10 and 11 (64-bit), macOS on Apple Silicon, and Linux on x86_64.

Can I print labels from an Excel or CSV list?

Yes. Use the Fill page to import a CSV or Excel file, choose a quantity for each row, preview the sheet and print the rows you select.

Does it support Zebra and other thermal label printers?

Yes. It can send raw ZPL to Zebra and compatible printers over USB or the network, and it has roll and thermal label templates.

Does it need an internet connection?

No. Designing and printing work offline. The only network use is an optional check for new versions, which asks for your permission first.

How is it different from gLabels?

gLabels Neo is an independent fork of gLabels. It adds a ribbon interface, colour themes, snapping and guides, the Fill page, kiosk deployment, ZPL thermal printing, an improved template designer and automatic updates. All credit for the original application goes to Jaye Evins and the gLabels contributors.
