# Ribbon UI for gLabels Neo

Design package for moving the main window to a ribbon (direction "A · Neo Ribbon").

| File | Purpose |
|---|---|
| [`SPEC.md`](SPEC.md) | The contract: tokens, dimensions, behaviour, command map, parity checklist |
| [`WORKPLAN.md`](WORKPLAN.md) | Branches, file ownership, the Theme API contract, order of work |
| [`PARITY.md`](PARITY.md) | Feature checklist to tick as work lands |
| [`QUESTIONS.md`](QUESTIONS.md) | Questions and substitutions, append only |
| [`mockups/`](mockups/) | 31 screens as PNG (and the standalone HTML they came from) |

Mockups are 1440 x 900 for screens (`s01`..`s20`) and 1200 x 760 for dialogs (`d01`..`d11`).
They were rendered at 100% scale; open the `.html` in a browser to inspect exact CSS values.
The mark is `brand/mark.svg`.
